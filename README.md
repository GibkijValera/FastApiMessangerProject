В интерпретаторе(Python 3.12):

pip install fastapi==0.119.0 pydantic[email] python-jose[cryptography] sqlalchemy uvicorn redis.asyncio puremagic passlib alembic aiosqlite python-multipart Jinja2 bcrypt==3.2.2

Приложение запускается на localhost:8000, тестовые страницы:
/auth/register
/auth/login
/auth/chats

Для запуска понадобится redis запущенный на 6379 порту(sudo systemctl start redis)

/auth/register четырехэтапная регистрация. Подтверждение почты - код выводится в консоль в самой IDE(пока не стал настраивать отправку письма на реальную почту)
Зарегистрированы 2 пользователя креды в файле /creditionals.txt
/auth/login классическая аутентификация с редиректом на /chats в случае успеха
/auth/chats Создан ровно один чат между зарегистрированными пользователями. В чате можно писать и прикреплять файлы незапрещенных расширений. Интерактивной возможности создавать чат пока нет, только через swagger, в ближайшем будущем сделаю такую возможность.

В самом проекте ручек гораздо больше, каждую можно отдельно протестировать через swagger(везде используются Pydantic модели, поэтому в Swagger будет подсказка по формату данных) или Postman(если возникнут сложности с авторизацией в Swagger)
